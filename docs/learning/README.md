## 고정 메모 템플릿

```text
파일:
무엇을 하는가:
어떻게 동작하는가:
문제점:
개선 방향:
회고 한 줄:

한마디로:

내가 이해한 흐름:
1.
2.
3.

같이 봐야 하는 함수:
- 

지금 헷갈리는 점:
- 

지금 보이는 문제:
- 

나중에 다시 볼 포인트:
- 
```

앞으로는 모든 파일을 먼저 아래 순서로 정리합니다.

1. 무엇을 하는가
2. 어떻게 동작하는가
3. 문제점
4. 개선 방향
5. 회고 한 줄

그 다음에 아래 학습용 메모를 붙입니다.

1. 한마디로
2. 내가 이해한 흐름
3. 같이 봐야 하는 함수 또는 파일
4. 아직 헷갈리는 점
5. 지금 바로 보이는 문제
6. 나중에 다시 확인할 포인트
