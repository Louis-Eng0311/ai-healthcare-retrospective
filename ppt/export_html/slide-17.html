구성 방식

EC2 한 대 안에서 Nginx, FastAPI, MySQL, Redis, AI Worker, App Worker를 Docker Compose로 분리 실행합니다. 문서 OCR은 FastAPI 앱 내부 서비스에서 처리합니다.

안정성 확보

MySQL·Redis healthcheck, FastAPI의 /api/health, 컨테이너별 restart 정책과 환경변수 분리로 기본 운영 안정성을 확보했습니다.

비동기 처리

가이드 생성과 챗봇 응답은 Redis 큐 기반 AI Worker가 처리하고, 알림 작업은 App Worker가 분리 처리합니다. 장시간 작업은 watchdog으로 정리합니다.

운영 환경 구성

Nginx가 API와 인증 UI 정적 파일을 라우팅합니다. 운영용 설정은 docker-compose.prod.yml, nginx 운영 설정 파일, certbot 스크립트 기준으로 분리돼 있습니다.
